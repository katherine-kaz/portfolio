Portfolio Website

A responsive personal portfolio website developed using **HTML5, CSS3, and JavaScript** to showcase my technical skills, academic projects, learning journey, and contact information.

**Live Website:** [View My Portfolio](https://portfolio-beryl-three-99.vercel.app/)

##  Features

- **Home Page:** Introduction with a dynamic, time-based greeting.
- **About Me:** Personal introduction and career goals.
- **Skills:** Displays technical and analytical skills.
- **Projects:** Showcases academic and personal projects with descriptions and GitHub repository links.
- **Contact:** Provides links to connect with me.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.
- **Interactive Navigation:** JavaScript-powered mobile navigation menu.
- **Dynamic Content:** Uses JavaScript to display a greeting based on the current time.

##  Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structures the website content. |
| CSS3 | Handles styling, layouts, and responsive design. |
| JavaScript | Adds dynamic content and interactive features. |
| Git | Tracks changes to the source code. |
| GitHub | Hosts the source code repository. |
| Vercel | Deploys and hosts the live website. |
