Natural Language Processing / GenAI

Comparative Analysis of Transformer-Based Generative AI Models for Automatic News Text Summarization

Source Code

Description

A data science study evaluating and benchmarking pre-trained Large Language Model architectures to automatically output abstractive summaries of news media files. The performance metrics of different models were evaluated against human gold-standard summaries to find the absolute optimized engine.

Tools & Technologies

Python, Generative AI, Transformer Architectures (Hugging Face API), T5-Small, FLAN-T5-Small, BART-Large-CNN, Pandas, BBC News Summary Dataset, ROUGE & BLEU Evaluation Metrics.

Contributions & Learning Outcomes

Sampled and prepared the news text matrices for model experimentation. Generated language summaries from raw files, calculated error matrices using ROUGE/BLEU pipelines, and mathematically determined BART-Large-CNN as the highest-performing architecture for automatic summarization.

Data Science & Analytics

Diabetes Hospital Readmission Analysis

Source Code

Description

An exhaustive data analysis pipeline exploring a complex clinical dataset containing 101,766 records across 50 data columns. The project builds data profiles to trace hospital readmission patterns, mapping factors causing a total 46.09% return rate, specifically highlighting the high-risk 70–80 age bracket.

Quick Stats Matrix:
  • Dataset Capacity: 101,766 patients | 50 columns
  • Not Readmitted: 53.91% (54,864 patients)
  • Readmitted > 30 Days: 34.93% (35,545 patients)
  • Readmitted < 30 Days: 11.16% (11,357 patients)

Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab / Jupyter Notebooks (`project1.ipynb`, `report.md`).

Contributions & Learning Outcomes

Performed extensive data inspection, stripped invalid null strings, handled missing values, and eliminated duplicate records. Generated demographic distributions and comparative plots mapping urgent versus chronic stay categories. Concluded that digital home tracking metrics and centralized communication remove conflicting treatment threats among seniors.
